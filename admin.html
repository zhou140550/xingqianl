📖 使用说明

✅ 改文字内容
1. 左边点击要改的课程
2. 直接在输入框里修改文字
3. 点下方「保存并生效」按钮
4. 刷新网页即可看到更新
🖼️ 换图片方法
1. 打开图床网站 imgbb.com（无需注册）
2. 上传新图片，复制图片链接
3. 把链接粘贴到对应的「图片链接」输入框
4. 点「保存并生效」
⚠️ 注意事项
• 老师资质、教学风格、授课班型：每行写一条，不要加符号
• 图片链接必须是完整的 http 开头的网址，或者 ./img/... 开头的本地路径
• 保存后如网页没变化，按 Ctrl+F5 强制刷新
修改内容后点击保存，网页将自动读取最新内容
